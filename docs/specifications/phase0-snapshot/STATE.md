## Binding decisions
- `internal/quicken/v9` (+ `v9fixture`) is a data package; production `internal/snapshot` never imports it. The reference schema arrives via `WithReference(label, sqlschema.Schema)`; `cmd/quarry` is now the one production caller of `v9.Reference`/`v9.ReferenceLabel`. (SCENARIO-01a)
- BR-6 scope lives in unexported `snapshot.scopeSchema`; `sqlschema` stays generic (no Quicken knowledge). Fingerprint and diff both run on scoped schemas. `SchemaInfo.ReferenceTables`/`ReferenceColumns` (`json:"-"`) are the scoped reference's counts, computed once in `schemaInfoFromDiff` for the CLI's human Schema line. (SCENARIO-01a, 01b)
- `Source` (`Open`/`Probe`/`Backup`/`Close`) and `Destination` (`Prepare`/`Backup`/`WriteManifest`/`CommitSnapshot`/`CommitManifest`/`FinalPaths`) are the only two ports in `internal/snapshot`. `FinalPaths(name) (snapshotPath, manifestPath string)` is a pure name→path prediction (no collision suffix yet); `Sync` calls it once right after computing `name` and sets `Manifest.Snapshot.Path`/`.Manifest` from it *before* `Encode`, so the bytes committed to disk already carry the paths `Sync` returns (BR-10) — fixes SCENARIO-01a's bug where the on-disk manifest's own path fields were empty. Production adapters are unexported (`newSQLiteSource`, `newDirDestination`); `internal/snapshot/export_test.go` re-exports them as `NewSQLiteSource`/`NewDirDestination` for the `snapshot_test` package only. Both are injectable in production via `WithSource`/`WithDestination`. (SCENARIO-01a, 01b)
- `Manifest.Encode()` is the only encoder (2-space indent, trailing `\n`); the four diff lists are always non-nil empty slices, never `null`. (SCENARIO-01a)
- `Sync`'s order is: reference check → `Source.Open` → `Source.Probe` → `Destination.Prepare` → `Destination.Backup` → integrity check → `ZACCOUNT` count → SHA-256 → schema diff → `Encode` → `WriteManifest` → `CommitManifest` → `CommitSnapshot`. Manifest commits before snapshot (BR-8). Nothing touches the snapshots directory before the probe succeeds. (SCENARIO-01a)
- `Sync` takes an already-resolved, absolute bundle directory path and joins `"data"` itself; it never resolves `~` or relative paths itself. (SCENARIO-01a, 01b)
- `internal/cli`: `Execute(ctx, args, stdout, stderr, srv *snapshot.Server, home string) error` builds a fresh `*cobra.Command` tree per call. `home` is resolved once in `cmd/quarry/run.go` via `os.UserHomeDir()` and passed in — `Execute` never reads the environment. `UsageError{msg}` (value type, not pointer) is a final exit-2 message; `Execute`'s default branch wraps any other cobra-native error (unknown flag, missing value, required flag, unknown command) as `UsageError{err.Error() + "; Run 'quarry sync --help' for usage."}` (U2, orchestrator-accepted wording). `runtimeError` (unexported, `Unwrap`) marks a `ResolveBundlePath`/`srv.Sync` failure as already-classified; `Execute` unwraps it and returns the original error unchanged (exit-1 default in `cmd/quarry`). Root: `SilenceUsage`/`SilenceErrors`/`DisableSuggestions` true, `CompletionOptions.DisableDefaultCmd` true, `help` subcommand kept, no `Run`/`Args` on root itself (orchestrator-accepted). (SCENARIO-01b)
- `internal/cli/sync.go`'s `RunE` calls `snapshot.ResolveBundlePath(home, quickenPath)` before `srv.Sync`, wrapping either's error identically as `&runtimeError{}`. A refusal from `ResolveBundlePath` never reaches `Destination.Prepare`. (SCENARIO-05)
- `--quicken` is no longer `MarkFlagRequired`. `RunE` branches on `cmd.Flags().Changed("quicken")` (not an empty-string check, so an explicit `--quicken ""` fails unambiguously in `ResolveBundlePath` rather than silently falling back) between `ResolveBundlePath` and the new `snapshot.DiscoverBundle(home)`. `DiscoverBundle` (`internal/snapshot/discover.go`) finds the sole top-level `*.quicken` directory in `~/Documents` — suffix matched case-insensitively (`strings.EqualFold`, matching R5's `.qdf`/`.QDF` precedent), dotfiles skipped, each name-matched entry `os.Stat`'d (not `DirEntry.IsDir()`) so symlinked bundles are followed and dangling ones or same-named regular files are silently skipped — then delegates its sole match to `ResolveBundlePath` rather than re-implementing R6/R7. Zero matches or a missing `~/Documents` is R1; more than one is R2 (names bytewise-sorted, which `os.ReadDir`'s own order already guarantees with no second sort); any other `ReadDir` error is R3 via `osReason`. (SCENARIO-04)
- `internal/snapshot.ResolveBundlePath(home, path) (string, error)` (exported) resolves a `--quicken` value to an absolute bundle path: `homepath.Expand` → `filepath.Abs` → `os.Stat` (not-exist → R4; other stat error → R7b) → case-insensitive `.qdf`/`.QDF` suffix on the path string, checked **before** the directory check (R5) → not-a-directory (R6) → unexported `validateData` (`os.Stat` + `os.Open`+immediate-close on `<path>/data`, R6 for missing/non-regular, R7 for any other fault, OS reason via the innermost `*fs.PathError.Err.Error()`). `RefusalError` (`internal/snapshot`, value type, `Error()` excludes the `quarry: ` prefix) is the shape every final one-line refusal returns. (SCENARIO-05)
- `internal/platform/homepath` (`Expand`/`Abbreviate`, both `(home, path string)`) is the one seam for home-relative path text; `internal/cli` no longer owns a local `abbreviateHome`. (SCENARIO-05)
- `internal/cli/render.go`: `renderSuccess` covers the exact-match Schema line only (`matches reference <label> (T tables, C columns)`); missing/unexpected-table rendering is SCENARIO-09/10's. Labels are `%-10s` left-padded; `formatThousands` assumes non-negative input (this package's only callers are byte/account/table/column counts). (SCENARIO-01b)

## Traps
- mattn/go-sqlite3's `Backup` is called on the **destination** connection: `destConn.Backup("main", srcConn, "main")`, not the other way around.
- A `database/sql.DB` pinned to `SetMaxOpenConns(1)`: never call a method that needs a pool connection while a `*sql.Conn` checked out from that same pool is still open — it deadlocks. Run the follow-up statement through the checked-out `*sql.Conn` itself.
- SQLite creates db files `0644`; pre-create the partial `0600` via `atomicfile.Create` (`O_EXCL`) before backing up into it.
- The backup API copies the WAL flag from the source header, so the destination needs `PRAGMA journal_mode = DELETE` before hashing, or it grows its own `-wal`/`-shm`.
- `atomicfile.Commit` is hard-link-then-remove, not `os.Rename` — refuses to clobber an existing destination atomically.
- Corrupting a SQLite file to fail `integrity_check` needs real page content — see `internal/snapshot/sync_faults_test.go`'s `newIndexCorruptedSnapshot` for the recipe (build the queried table first and small, corrupt a separately-indexed filler table's last pages).
- `dirDestination.WriteManifest`'s `f.Write(data)` failure branch is permanently unreachable through the real adapter; marked `// unreachable` in code, not an open debt.
- `os.UserHomeDir()`/`v9.Reference(ctx)` failures happen in `cmd/quarry/run()` before `cli.Execute` runs — routing them through the `UsageError` check would wrongly exit 2 on an unset `HOME`.
- Cobra's `c.Find` failure (unknown command) returns a plain error straight from `ExecuteContext` — `Execute`'s default branch, not a named check, catches it. Without `DisableSuggestions` on root, a near-miss like `synk` would append `"\n\nDid you mean this?\n\tsync"`, breaking the one-stderr-line rule.
- `SilenceErrors`/`SilenceUsage` on the root command alone suppress printing for every subcommand (cobra checks the root's flags, not the found command's).
- Cobra falls back to reading `os.Args` when `SetArgs(nil)` — `Execute` requires a non-nil `args` slice and does not normalize; its one production caller (`cmd/quarry/run.go`, fed from `main.go`'s `os.Args[1:]`) never passes nil, and slicing a non-nil slice never produces nil.
- A pre-cancelled or expired `ctx` reaching `v9.Reference` fails at `sqlite.OpenMemory`'s `PingContext`, not just at a real database's I/O — the `:memory:` DB is not exempt from context checks. Don't mark a ctx-consuming call `// unreachable` on the strength of "no external resource can fail" alone.
- `Sync` still wraps every error it returns as `fmt.Errorf("sync %s: %w", bundlePath, err)`. `ResolveBundlePath`'s own refusals never pass through `Sync`, so this doesn't bite there — but a refusal raised *inside* `Sync` (R8–R14) must be returned unwrapped (or unwrapped via `errors.As` before printing), or the `sync <path>: ` prefix corrupts the exact-copy contract.
- `ResolveBundlePath`'s R7 readability check is a plain `os.Open`+immediate-`Close`, never a read — moving it into `Sync` as literal "BR-8 step 1" must keep that shape: closing any fd drops every fcntl lock the process holds, so doing this after `Source.Open` would drop SQLite's lock mid-backup.
- `os.Stat` already follows symlinks; `ResolveBundlePath` does not `Lstat` or `filepath.EvalSymlinks` — do not resolve symlinks there, since `t.TempDir()` resolves through `/private/var` on macOS and `~`-abbreviation against an unresolved injected `HOME` would break.
