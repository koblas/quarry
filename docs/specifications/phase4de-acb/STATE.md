- ACB types (`report/acb.go`): `ACBRequest{Classification, Today, Year, Adjustments}`, `ACB{AsOf, Year, FirstRate, Years, Securities, AdjustmentIssues}`, `ACBYear{.., ReturnOfCapitalGain}`, `ACBSale{.., AccountID, Account, PossibleSuperficialLoss, UnknownCost}`, `ACBSecurity{.., Incomplete, NoRate}`, `ACBEvent{.., Rate, CAD, Outlays *int64, Held, ACB, Gain, Realized, Unvalued, UnknownCost}`. Money int64 CAD cents, shares `*big.Rat`; fields ADDITIVE, never retyped. `Rate` USD only; `Outlays` only on a sale; `Amount` nil only for adjustment events. `report.Millionths` is the SOLE Rat→millionths rounding (text `humanize.Shares` and JSON `document.Shares`); per-share `Rat.FloatString(4)` (SCENARIO-08a, 08b, 14)
- Walk (`acb_walk.go`): pool = `Classification.Of == false` accounts only, one pool per security across accounts. `acbTiers`: buy/reinvest/add_shares 0, split 1, sell/remove_shares 2; other actions skipped; events after `Today` dropped. Stored shares are SIGNED (sell/remove negative; fixtures use stored sign), walk uses `Abs`. Sale: outlays = commission rounded half away, proceeds = amount + outlays, each converted to CAD as ONE amount; gain = proceeds - outlays - ACB removed; `acbPool.take(sold)` removes round-half-away pro-rata ACB, sold >= held takes all and resets to 0. Year = `Date.Year()`; year totals sum per-sale CAD. Sort: sales date/tier/source_id; securities name (case-folded) then id; events date/tier/source_id (SCENARIO-08a, 10)
- Splits apply once per date per security from pool rows only; a same-day split after the first is skipped, NO event. `splitShares(count, new, old)` is the one multiply (walk and held count); nil/non-positive guard is `// unreachable:`. Held-count rule differs: each account's own split row scales that account (SCENARIO-08a, 12)
- Zero-unit rule: `movesNoUnits(tx)` runs first; add_shares units <= 0 and remove_shares 0 units make NO event (so no warning 5). Reinvest uncovered. remove_shares: no sale, no `Realized`, event `Shares` positive, `Amount` the row's own; add_shares event `Amount` likewise (SCENARIO-10)
- FX / no-rate (S14): `rateOn` = latest rate on or before the date; `unvalued(tx, rate)` = `needsConversion(tx)` AND `Convert` fails; sets `ACBEvent.Unvalued` and earliest `ACBSecurity.NoRate{Date, Currency}`; `ACB.FirstRate` = `history.Rates[0].Date`. Exclusion is security-wide and permanent: `walkACB` appends sales and ROC excess only when `NoRate == nil`, BEFORE `markSuperficialLosses` and `acbYears`; events stay in `securities[].events`; JSON event `cad`/`gain` null when `Unvalued`. `Incomplete` = unknown-cost span OR `NoRate != nil` (SCENARIO-08a, 14)
- No-cost span (S13a): `noCostAcquisition(tx)` is the ONE predicate (add_shares or reinvest, nil cost, units > 0); `securityWalk.unknownCost` opens on it, clears when a disposition leaves 0; `ACBEvent.UnknownCost` on no-cost acquisitions and on sell/remove_shares inside the span; `ACBSale.UnknownCost` copies its sell; `(ACBYear).UnknownCostSales()` is the ONE count (JSON, text suffix, S19). Shares-without-cost (S13b) detector = add_shares, `SecurityID != nil`, `noCostAcquisition`, `Classification.Of` non-nil false; id `shares-without-cost:<itxn id>`, newest first; JSON keys after `splits`, CSV `findingInvestmentCSVColumns` = 4 after `fix` (SCENARIO-13a, 13b)
- Adjustments (S11): mapped to `report.ACBAdjustment` in cli only (`acbAdjustmentsOf`; S19 same); day order tier 1: split, every RD, every ROC; not-held = pool 0 at the item's tier-1 point; unknown = id not in `Securities`; skipped items make no event. Repeat issue only between APPLIED items. Events `Amount` nil, `Shares` 0, `CAD` = cash-flow sign (ROC +, RD -). ROC above ACB: ACB 0, excess = event `Gain`, `Realized`, `Outlays` nil, summed into `ReturnOfCapitalGain`; ROC equal to ACB: no gain, no warning 8 (SCENARIO-11)
- Superficial losses (S12, `acb_superficial.go`): `markSuperficialLosses` runs BEFORE `acbYears`, reads `InvestmentHistory.Transactions` file-wide (rows <= Today). Loss = `Gain < 0` strictly; acquisition = tier 0 and units > 0 within day±30 inclusive, same day counts; held at day+30 (or Today) = SOME (account, security) holding > 0; group = same id or same non-empty case-sensitive ticker (`groupingTicker`, also `(ACB).SharedTickers()`). `report` keeps its own holding count mirroring `duckstore.holdingSpans`; S21 cross-checks (SCENARIO-12, 14)
