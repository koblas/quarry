Scenarios complete: SCENARIO-01..01. Last updated by SCENARIO-01.

## Binding decisions
- Optional entities (`Security`, `SecurityQuote`) live in one slice in `internal/importer/entities.go` with generated placeholders; missing → that data is empty, never a refusal. S02 appends `Position`, S04 appends `Lot` (SCENARIO-01)
- Quote selection: deleted, NULL-date, NULL-price quotes and quotes of a non-imported security are dropped BEFORE the highest-`Z_PK` dedupe per (security, UTC day); every remaining quote is parsed, so an unreadable superseded duplicate still refuses. `prices` PK `(security_id, date)` guarantees one row per day to 4b readers (SCENARIO-01)
- `store.Price.Price` is int64 millionths, DECIMAL(18,6); "too large" = |rounded| >= 10^12 checked after half-even rounding on decimal text (`big.Rat`, not float). S02 shares (also DECIMAL(18,6)) reuse the same scale constant (SCENARIO-01)
- `securities.currency` stored as recorded: NULL only when NULL, `""` stays `""` (SCENARIO-01)
- `securities_rows`/`prices_rows` are nullable BIGINT after `rates_fetch_error`; filled positionally by `importRunRows`, carried through `optionalRunColumns`/`carriedRun`, read with COALESCE→0 in `status.go`. S02/S04 append theirs the same way (SCENARIO-01)
- `FormatVersion = 6` from SCENARIO-01; later 4a schema changes do not bump it again (SCENARIO-01)
- A quote whose security is deleted/absent is skipped silently (analogue of the I4-6 rule), no refusal (SCENARIO-01)

## Traps
- ZNAME is scanned into a plain `string`: a NULL name fails the import loudly via `rows.Scan` until SCENARIO-03 adds the refusal; switching to `sql.NullString` earlier makes a nameless security import silently (SCENARIO-01)
- `ZQUOTEDATE` must be `CAST(... AS REAL)` (as `transactions.go:37-40`) or the driver returns a Unix-epoch `time.Time` (SCENARIO-01)
- A v9fixture row without its default `Z_ENT` is silently filtered by `Z_ENT = ?`; tests pass empty (SCENARIO-01)
- Half-even on `float64` passes most rows and fails ties; round on the decimal text (SCENARIO-01)
- `plugin/skills/quarry/references/schema.md` is regenerated by `go test ./cmd/quarry/ -run Test_skill_schema_reference_matches_the_committed_file -update` (pattern `SchemaReference` matches nothing) (SCENARIO-01)
