# Guides

Each guide gets one task done. They assume you know what quarry is ([Concepts](../concepts/index.md)) and have a store ([Your first question](../tutorials/first-question.md)). They point at the [Reference](../reference/index.md) for every flag and key and do not repeat it.

## Ask

- [How to use quarry with Claude](use-with-claude.md): install the plugin in Claude Code, the MCP server in Claude Desktop, and ask in plain words.
- [How to query the store with SQL](query-with-sql.md): read-only SQL for a question no command answers.
- [How to get a monthly summary](monthly-summary.md): last month's unusual charges, new recurring charges and net worth change, by hand or on a schedule.

## Maintain

- [How to clean up your Quicken data](clean-up-quicken.md): work through the findings, fix them in Quicken, confirm they are gone.
- [How to work out capital gains](capital-gains.md): classify accounts, add T3 amounts, read the adjusted cost base worksheet.
- [How to manage snapshots](snapshots.md): list them, keep more or fewer, rebuild the store from an older one.
- [How to configure quarry](configure.md): the optional config file.

## Develop

- [How to write documentation](develop/docs.md): where a page belongs on this site and how to check it.
